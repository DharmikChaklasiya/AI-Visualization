-- i have the finbert model and tweets as my dataset. Now im curious as to why it classifies certain tweets wrong. Can i somehow retrieve the decision making from finbert and look into it?

Perfect. In that case, you don't need to rebuild or retrain FinBERT. The Hugging Face `pipeline()` API actually gives you access to the underlying model and tokenizer.

The key is to access those two components directly.

## 1. Extract the model and tokenizer

Suppose your current code looks something like this:

```
from transformers import pipelineclassifier = pipeline(    "sentiment-analysis",    model="ProsusAI/finbert")
```

You can retrieve the underlying components:

```
model = classifier.modeltokenizer = classifier.tokenizermodel.eval()print(model)print(tokenizer)
```

Now you have direct access to FinBERT's architecture, which allows you to use explainability libraries such as Captum.

## 2. Apply Integrated Gradients to your existing pipeline

First install Captum:

```
pip install captum
```

Then:

```
import torchfrom captum.attr import LayerIntegratedGradients# Get model and tokenizer from existing pipelinemodel = classifier.modeltokenizer = classifier.tokenizermodel.eval()# Define forward functiondef forward_func(input_ids, attention_mask):    outputs = model(        input_ids=input_ids,        attention_mask=attention_mask    )    return outputs.logits# Access FinBERT's word embedding layerembedding_layer = model.base_model.embeddings.word_embeddingslig = LayerIntegratedGradients(    forward_func,    embedding_layer)def explain_tweet(tweet, n_steps=50):    device = next(model.parameters()).device    inputs = tokenizer(        tweet,        return_tensors="pt",        truncation=True,        max_length=128    )    input_ids = inputs["input_ids"].to(device)    attention_mask = inputs["attention_mask"].to(device)    # Get prediction    with torch.no_grad():        logits = forward_func(input_ids, attention_mask)        probabilities = torch.softmax(logits, dim=1)    predicted_class = logits.argmax(dim=1).item()    predicted_label = model.config.id2label[predicted_class]    # Baseline: replace normal tokens with padding    baseline_ids = torch.full_like(        input_ids,        tokenizer.pad_token_id    )    # Preserve special tokens    special_tokens = tokenizer.get_special_tokens_mask(        input_ids[0].tolist(),        already_has_special_tokens=True    )
```

This gives you token-level attribution scores for the predicted class.

A positive attribution pushes the model towards the selected class; a negative attribution pushes against it. These are relative contributions, not probabilities.

## 3. An interesting extension: explain the correct class too

This is particularly useful for your research.

Imagine:

- Actual label: Positive
- FinBERT prediction: Negative

Instead of only asking why FinBERT predicted negative, you can calculate attributions twice:

1. Target the predicted negative class.
2. Target the actual positive class.

This lets you investigate which words support each competing interpretation.

You can change:

```
target=predicted_class
```

to:

```
target=actual_class
```

where `actual_class` is the numerical class ID corresponding to your dataset's ground-truth label.

This comparison can reveal whether FinBERT is overlooking positive signals or incorrectly interpreting negative expressions.

## 2. Create a function to highlight influential words

This function takes the output of `explain_tweet()` and generates a color-coded visualization.

- Green = supports the predicted sentiment.
- Red = opposes the predicted sentiment.
- Stronger color = stronger contribution.
- Hover over a word to see its attribution score.

```
from html import escapedef visualize_tweet(result):    tokens = result["tokens"]    scores = result["attributions"]    # Normalize scores for visualization    max_score = max(abs(s) for s in scores) or 1    html_tokens = []    for token, score in zip(tokens, scores):        # Remove WordPiece notation        word = token.replace("##", "")        intensity = abs(score) / max_score        if score > 0:            color = f"rgba(0, 180, 0, {intensity:.2f})"        else:            color = f"rgba(220, 0, 0, {intensity:.2f})"        html_tokens.append(            f'<span title="Attribution: {score:.5f}" '            f'style="background-color:{color}; '            f'padding:4px; margin:2px; '            f'border-radius:4px;">'            f'{escape(word)}</span>'        )    highlighted_tweet = " ".join(html_tokens)    html_content = f"""    <html>    <body style="font-family:Arial; padding:25px;">        <h2>FinBERT Prediction</h2>        <p>            <b>Sentiment:</b> {escape(result["prediction"])}        </p>        <p>            <b>Confidence:</b>            {result["confidence"][                list(model.config.id2label.keys()).index(                    int(next(                        k for k, v in model.config.id2label.items()                        if v == result["prediction"]                    ))                )] * 100:.2f}%        </p>        <h3>Tweet explanation</h3>        <div style="font-size:20px; line-height:2;">            {highlighted_tweet}        </div>        <hr>        <p>            <span style="background-color:rgba(0,180,0,0.5)">            Positive contribution            </span>
```

One small improvement: you can simplify the confidence calculation by adding the predicted class index to the dictionary returned by `explain_tweet()`:

Then use this directly in the visualization:

confidence = result["confidence"][result["predicted_class"]]

misclassified = []for _, row in df.iterrows():    result = explain_tweet(row["tweet"])    if result["prediction"].lower() != row["actual_sentiment"].lower():        result["actual"] = row["actual_sentiment"]        misclassified.append(result)
