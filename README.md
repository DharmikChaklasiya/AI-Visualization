Model: https://huggingface.co/ProsusAI/finbert 
To perform our task, we use FinBERT from Hugging Face.FinBert is a pre-trained NLP model that is built on the BERT language model and specialized for the finance domain.

Dataset: https://huggingface.co/datasets/zeroshot/twitter-financial-news-sentiment

Task: 
We want to perform sentiment analysis for stocks using the Twitter Financial News dataset which contains finance-related tweets that express a certain sentiment towards individual stocks (bullish, bearish and neutral scenarios). Our goal is to explore the model behaviour by visual analysis of finance tweets to investigate systematic sentiment-classification errors. Based on that, we will identify the model’s internal behaviour to see for example which words drive predictions.
